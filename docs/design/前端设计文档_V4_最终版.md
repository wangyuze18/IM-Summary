# 企业 IM 智能摘要平台 — 前端设计文档（最终版）

## 文档属性

| 项目 | 内容 |
|------|------|
| 版本 | V4.6 |
| 日期 | 2026-08-27 |
| 应用形态 | 桌面端离线分析应用（无需个人登录） |

## 1. 设计边界

1. **无需登录**：启动后直接进入离线会话分析工作台。
2. **纯文本**：原始群聊仅展示文本消息、@提及、发送者和时间，不展示文件/图片/链接富媒体组件。
3. **双分析模式**：用户可在启动分析时选择 **Agent 工作流团队模式** 或 **单模型**。
4. **模型可配置**：支持选择接口协议（OpenAI 兼容 / Anthropic / 自定义）+ Base URL + API Key + Model Name。
5. **模型状态可见**：展示模型可用性与思考模式支持状态。
6. **评测历史与导出**：保留评测历史记录列表与导出功能；**不提供自动对比组件**，对比分析由用户导出后人工完成。
7. **桌面端宽屏**：推荐 1440×900 及以上，最低 1280，低于阈值时右侧辅助区优先折叠。

## 4. 左侧：离线会话区域

### 4.1 导入离线会话（支持批量）

- "导入离线会话"为左侧最显眼主按钮，支持点击选择文件和拖拽导入，**支持一次选择/拖入多个文件进行批量导入**
- 单文件导入流程：选择文件 → 上传至后台 → 数据检查 → 预览 → 确认导入（预览页展示群名、消息数、成员数、画像数、关系数以及**是否携带黄金摘要**）
- 批量导入流程：
  - 多文件同时上传，后台逐个预检查，前端展示逐文件状态列表（文件名 / 校验结果 / 警告摘要）
  - 校验通过的文件可切换查看简要预览；失败文件标红并可单独移除或重试，不阻断其他文件
- 导入失败不创建会话；警告在确认页集中提示；批量导入时单个文件失败不阻断其他文件
- 单文件导入完成后新会话自动加入列表并选中；批量导入完成后全部新会话加入列表，默认选中第一个成功项

### 4.2 会话搜索与列表

| 字段 | 展示规则 |
|------|----------|
| 会话标题 | 主文本，最多两行，超长省略 |
| 导入日期/时间 | 次级信息 |
| 消息数 | 会话规模参考 |
| 状态 | 待分析 / 分析中 / 已完成 / 失败 |
| 选中态 | 浅蓝背景 + 蓝色描边 |

## 5. 分析模式选择（新增）

在主工作区顶部（工作流区域上方）提供**模式切换器**，用户启动分析前选择：

| 模式 | 显示名称 | 说明文案 |
|------|----------|----------|
| `agent-workflow` | Agent 团队模式 | 7 个 Agent 协同分析，质量优先 |
| `single-model` | 单模型 | 单一模型直接生成，作为基线对照 |

**交互规则**：
- 默认选中 Agent 团队模式
- 切换模式不影响已完成的分析结果
- 分析进行中禁用切换
- 每次启动分析记录所用模式；摘要区标注当前摘要来自哪种模式
- 同一会话可分别用两种模式运行，产生不同 runId 与 SummaryResult

**模式徽标**：摘要卡片头部显示模式标签（如“Agent 团队模式”或“单模型”），便于用户区分不同运行的结果。

## 6. Agent 工作流区域

### 6.1 Agent 团队模式下的工作流展示

保留形象化 Agent 风格，标准 8-Agent 双任务链路与两组并行关系：

```
Context & Event Agent
        │
   ┌────┴───────────────┐
   ▼                    ▼
State Agent      User Context Agent     ← 并行
   └────┬───────────────┘
        ▼
Personalized Relevance Agent
        ▼
   Summary Agent
        │
   ┌────┴───────────────┐
   ▼                    ▼
Factual Auditor  Personalization Auditor  ← 并行
   └────┬───────────────┘
        ▼
     Final
```

| Agent | 前端短说明 |
|-------|-----------|
| Context & Event Agent | 主题与事件抽取 |
| State Agent | 决议/待办/状态判断 |
| User Context Agent | 职位/职责/关系上下文 |
| Personalized Relevance Agent | 用户相关性与重要性 |
| Summary Agent | 结构化摘要生成 |
| Factual Auditor | 事实/遗漏/状态审核 |
| Personalization Auditor | 个性化合理性审核 |

### 6.2 单模型下的展示

- 不展示团队工作流动画
- 显示简化的单步进度状态："模型生成中 → 完成"
- 同样展示已进行时间

### 6.3 状态与动画（团队模式）

| 状态 | 视觉 | 要求 |
|------|------|------|
| 等待 | 低饱和静止 | 轻微待机动作，不闪烁 |
| 进行中 | 角色动作 + 蓝色高亮 + 流动连接线 | 只表达阶段，不展示思维过程 |
| 已完成 | 绿色对勾 + 短暂完成动画 | 完成后恢复静止 |
| 警告 | 黄色标识 | 可查看结构化告警 |
| 失败 | 红色标识 | 显示可重试入口 |
| 修订中 | Summary 与 Auditor 之间回传状态 | 只在审核要求修订时出现 |

### 6.4 时间与进度

- 右上角显示"已进行：00:00:18"，从本次 Run 启动时间累计
- 不显示"预计剩余时间"
- 整体进度来自后端 overallProgress，前端不自行推算
- 并行节点在连线和状态上可识别

## 8. 最终摘要与黄金摘要

### 8.1 AI 最终摘要

- Markdown 渲染：标题、列表、加粗、表格、引用、任务列表；标题不使用表情符号，正文保持专业简洁
- 结构与规范一致：abstractPoints、decisions、todos、topics、openIssues、keyInfo
- 头部显示**模式标签**（Agent 团队模式 / 单模型）与版本号
- 顶部保留局部"复制 / 导出"操作；导出 Markdown 为必选，JSON 次级
- 摘要证据可点击回跳原始消息
- 同一会话存在多个版本时支持版本切换

### 8.2 黄金摘要（强制来源：仅导入携带）

黄金摘要**只能来自导入文件中的 `goldenSummary` 字段**，不提供手动输入、粘贴或上传入口，避免非标准来源带来的处理与评测口径问题。
- 导入文件携带时，导入完成后直接在黄金摘要区展示
- 导入文件未携带时，不提供后续补充入口

| 状态 | 界面行为 |
|------|----------|
| 导入文件未携带 | **不展示黄金摘要区，也不展示评测区**；主工作区只显示 AI 最终摘要 |
| 导入文件携带 | 完整渲染黄金摘要，与 AI 摘要并排；评测可用 |
| 重新导入含新黄金摘要的会话 | 产生新 goldenVersion，旧评测记录标记过期 |
| 删除会话 | 黄金摘要随会话域数据一并删除 |

黄金摘要只用于评测与人工对照，不参与摘要生成。导入携带的结构化黄金摘要与 AI 摘要使用**同一 Markdown 渲染版式**（头部模式标签显示“黄金摘要（人工参考）”），便于人工逐栏对照。

## 9. 评测区域

### 9.1 当前评测指标

紧贴摘要对比下方，单行指标卡：

| 指标 | 显示规则 |
|------|----------|
| Accuracy / 准确率 | 数值 + 名称，方向箭头 ↑ |
| Recall / 召回率 | 数值 + 名称，方向箭头 ↑ |
| 关键信息遗漏率 | 数值，方向箭头 ↓ |
| ROUGE-L / 文本相似度 | 数值，方向箭头 ↑ |
| 综合质量评分（LLM Score） | 0-100 分，方向箭头 ↑；旧评测记录缺失时显示“—” |

- 黄金摘要只存在于导入携带的场景；未携带时评测区与黄金摘要区整体隐藏，不显示"不可评测"占位态
- 不提供综合评价、星级、奖章等主观汇总组件

### 9.2 评测历史（新增）

评测区下方提供**评测历史列表**（可折叠）：

| 列 | 说明 |
|----|------|
| 评测时间 | evaluatedAt |
| 模式 | Agent 团队模式 / 单模型（带徽标） |
| 摘要版本 | summaryVersion |
| 黄金版本 | goldenVersion |
| 准确率 ↑ | 数值 |
| 召回率 ↑ | 数值 |
| 遗漏率 ↓ | 数值 |
| 文本相似度 ↑ | ROUGE-L 数值 |
| 综合质量评分 ↑ | 0-100；旧记录缺失显示“—” |

**交互规则**：
- 支持按模式筛选（全部 / Agent 团队模式 / 单模型）
- 点击某条记录可查看该次评测的详细指标（含综合质量评分，旧记录缺失时该项不展示）
- 同一指标列的**最优值加粗**展示，非最优值保持常规样式；方向通过表头箭头（↑ 越高越好 / ↓ 越低越好）表达，不在单元格内重复标注文字说明
- **不提供自动对比组件**：用户如需对比，通过导出后人工分析
- 过期记录灰显但保留

### 9.3 评测导出

评测历史区提供"导出"按钮：

| 格式 | 用途 |
|------|------|
| CSV | 表格形式，便于人工对比分析（推荐） |
| JSON | 完整结构化数据 |
| Markdown | 可读报告 |

导出内容为当前筛选条件下的评测历史记录（含模式、版本、四项指标）。

### 10.1 群成员概览

- 默认展示群名称、总人数、5–6 个头像和角色数量概览

- 默认只画 targetUser 与 3–5 个最相关成员的关系
- 节点仅显示姓名或缩写；工号放入悬停信息
- 职位用颜色圆点区分；关系边统一实线，线上标注中文关系名称；关系字段允许任意中文描述（如“上下级”），原样展示，仅对常见英文标识（如 reports_to）兜底映射为中文
- 提供"查看完整关系图"入口（抽屉/模态框）

## 11. 模型 API 设置（增强）

### 11.1 基本原则

- 无需登录；配置面向当前桌面应用连接的 Web 后台
- 未配置有效模型时允许导入和查看，不允许启动分析
- API Key 密码框输入，保存后仅掩码显示
- "测试连接"与"保存配置"分离

### 11.2 API 配置档案字段

| 字段 | 控件 | 规则 |
|------|------|------|
| 配置名称 | 文本框 | 如"主力大模型"、"基线模型" |
| **接口协议** | 下拉框 | **OpenAI 兼容 / Anthropic / 自定义**（新增） |
| Base URL | 文本框 | 必填；保存前基础格式校验 |
| API Key | 密码框/明文展示 | 必填；在线模式从后端回显明文，可编辑，每次保存均提交后端 |
| Model Name | 下拉框/文本框 | 必填；支持自动获取模型列表后下拉选取，也可手填（见 11.7） |
| 连接状态 | 状态标签 | 未测试 / 测试中 / 可用 / 失败 |
| **思考模式** | 状态标签 | 支持 / 不支持 / 未检测（新增） |
| 操作 | 按钮组 | 测试连接 / 保存 / 复制配置 / 删除 |

### 11.3 模型状态展示（新增）

测试连接后，配置卡片显示两项状态：

```
连接状态：● 可用（绿色） / ● 失败（红色） / ○ 未测试（灰色）
思考模式：✓ 支持 / ✗ 不支持 / - 未检测
```

- 连接失败时显示简短错误信息（不含敏感内容）
- 思考模式状态由后端探测返回，前端只展示
- 状态不代表永久可用，启动分析时仍可能失败

### 11.4 思考模式开关

- 当模型 `thinkingModeSupported = true` 时，设置中显示"启用思考模式"开关
- 默认关闭（节省成本）；开启后分析时传递思考模式参数
- 思考模式不支持时开关隐藏或禁用

### 11.5 Agent 与模型绑定

- 默认：7 个 Agent（或单模型）继承同一配置；单模型模式与评测判分模型也可在模型设置中单独指定（未指定时继承默认配置）
- 可选覆盖：单个 Agent 指定其他配置档案
- 高级绑定区域按需展开，默认收起

### 11.6 配置状态与分析联动

| 配置状态 | 分析行为 |
|----------|----------|
| 未配置 | 禁止启动分析，提示"请先配置模型 API" |
| 已保存、未测试 | 启动时先轻量校验；失败则阻止 |
| 测试可用 | 允许启动 |
| 绑定无效 | 设置页指出具体 Agent，阻断启动 |
| 运行中修改 | 只影响后续 Run |

### 11.7 模型列表自动获取（V4.2 新增，V4.3 调整为自动触发）

- Model Name 在满足条件时**自动获取**模型列表，无需手动点击按钮：协议为 OpenAI 兼容、Base URL 格式有效、且已填 API Key（编辑已保存档案时未填新 Key 则沿用已存凭据）。
- 条件满足后以后端 `POST /api/model-profiles/models` 拉取，输入变化时防抖重取；成功后 Model Name 以下拉框呈现全部模型供选取，并保留「自定义输入…」选项回退手填。
- 仅 OpenAI 兼容协议支持自动获取；Anthropic/自定义协议、离线（后端不可达）时保留手填输入。
- 获取中显示加载态；失败以内联提示展示简短错误，不阻断保存。
- 桌面端与后端跨源通信：后端对 `/api/**` 开启 CORS，允许任意 Origin（Demo 级、本地桌面场景）。

## 12. 跨区域联动

| 用户操作 | 联动行为 |
|----------|----------|
| 切换左侧会话 | 更新工作流、群聊、摘要、黄金摘要、评测和右侧上下文 |
| 点击摘要证据 | 原始群聊滚动并高亮对应 messageId |
| 点击成员头像/@人名 | 右侧成员或组织关系节点高亮 |
| 点击 Agent 卡片 | 显示阶段说明、状态、时间、结构化告警；不显示思维链 |
| 导入携带黄金摘要的会话 | 黄金摘要区与评测区自动展示，评测状态为"可评测" |
| 切换分析模式 | 只影响下次启动分析 |
| 重新分析 | 创建新 Run，计时重新开始；旧摘要保留 |
| 打开模型设置 | 打开设置抽屉；保存后更新状态，不改已有结果 |

## 13. 页面状态规范

| 状态 | 主界面表现 |
|------|-----------|
| 未导入会话 | 左侧导入入口；主工作区空状态说明 |
| 已导入未分析 | 显示群聊/成员；Agent 均等待；模式切换器可用 |
| 分析中（团队模式） | Agent 动画与计时运行；摘要区生成中 |
| 分析中（单模型模式） | 单步进度状态；摘要区生成中 |
| 分析完成 | 摘要可读可导出；模式徽标标注来源 |
| 部分 Agent 失败 | 失败节点红色；保留可用数据 |
| 无画像/关系 | 个性化降级提示 |
| 无黄金摘要（导入未携带） | 黄金摘要区与评测区整体隐藏；摘要完全可用 |
| 模型未配置 | 会话可查看；"开始分析"禁用并提示配置 |

## 17. 前端验收清单

1. 无个人登录、消息中心、知识库等无关模块
2. 离线会话可导入、搜索和切换；历史状态清晰
3. **支持分析模式切换（Agent 团队 / 单模型基础），并在摘要标注模式徽标**
4. 团队模式展示标准 8-Agent 双任务工作流；单模型模式展示摘要与重要消息双任务简化进度
5. Agent Run 显示已进行时间，不显示预计剩余时间
6. 原始群聊仅展示文本/@/时间/人员
7. 最终摘要 Markdown 正确渲染，局部支持复制和导出
8. 黄金摘要仅来自导入携带；未携带时黄金摘要区与评测区整体隐藏，无手动输入/上传入口
9. 评测区只展示 5 类指标（准确率、召回率、关键信息遗漏率、文本相似度、综合质量评分），不含综合评价
10. **评测历史列表支持查看、按模式筛选与导出（CSV/JSON/Markdown）；无自动对比组件**
11. 右侧成员/组织关系保持紧凑，完整关系二级展开
12. 摘要证据、@人员具备联动定位能力
13. **模型设置支持协议选择（OpenAI 兼容/Anthropic/自定义）、Base URL、API Key、Model Name**
14. **测试连接后展示连接状态与思考模式支持状态**
15. **思考模式支持时可手动开启；不支持时开关禁用**
16. 7 个 Agent 默认继承统一模型配置，支持按 Agent 覆盖；未配置有效 API 时禁止分析
17. API Key 在线模式明文回显、可编辑且每次保存提交后端；配置修改只影响后续 Run
18. 应用重启后可恢复会话与配置；断线后重连可恢复运行状态
19. 浏览本地数据不依赖模型在线；只有启动新 Run 才要求模型可用

## 18. V4.4 迭代调整（去 mock 与交互修正）

1. **数据全部来自后端**：在线模式下群组信息、组织关系、消息流均由会话详情/组织图接口提供，不再展示任何 mock 数据；离线回退仅供无后端时演示。
2. **黄金摘要在线查看**：后端新增 `GET /api/sessions/{id}/golden-summary` 返回内容，前端直接渲染真实 Markdown；不再展示「后端暂未提供」占位。黄金摘要标题不再带「导入携带 · v1」标签。
3. **会话删除**：会话列表项支持删除（二次确认），在线时调用 `DELETE /api/sessions/{id}`（后端级联清理）并刷新列表。
4. **时间范围**：群聊头部时间范围由会话消息的首/末时间戳计算展示，不再固定为「—」。
5. **双模式状态独立**：模式切换器按模式各自展示状态（分析中/已完成/等待）；一个模式运行时另一模式显示「等待」，未运行的模式不再显示「已完成」。
6. **无黄金摘要时**：黄金摘要列与评测指标区整体隐藏，仅保留智能摘要。
7. **单用户 Demo**：不提供用户切换能力，成员列表不标注「当前用户」。
