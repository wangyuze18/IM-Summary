# 摘要 JSON → Markdown 渲染规范

## 版本: V1.0
## 日期: 2026-08-26
## 适用范围: 两种分析模式的 SummaryResult 渲染、Markdown 导出

---

## 1. 总体原则

1. **两种模式统一渲染**：agent-workflow 与 single-model 模式产出相同结构的 SummaryResult，使用同一套渲染规则，保证导出格式一致、便于人工对比。
2. **空节省略**：某字段数组为空时，该小节整体省略（不显示空表格/空列表）。
3. **实体保真**：@提及、人名、版本号、系统名原样保留。
4. **渲染时机**：
   - 后端在固化 SummaryResult 时生成 `markdown` 字段（导出接口直接使用）
   - 前端展示时也可直接渲染该字段

---

## 2. 标准模板

```markdown
# 工作群聊分析简报
**群组名称:** {groupName}
**报告周期:** {period}
**分析模式:** {Agent 团队模式 | 单模型基础模式}

---

### 摘要
* {abstractPoint1}
* {abstractPoint2}
* {abstractPoint3}

---

### ❗ 决议事项
* **决议{N}:** {title}
  * **背景/上下文:** {context}
  * **状态:** {status}

---

### 📋 待办事项

| 优先级 | 任务内容 | 负责人 | 截止日期 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| {priority} | {task} | {owner} | {dueDate} | {status} |

---

### 💬 主要议题讨论
**议题 {N}: {title}**
* **时间段:** {timeRange}
* **主要参与者:** {participants}
* **过程概述:** {process}
* **核心结论:** {conclusion}

---

### ❓ 待解决问题与关键信息
* **待解决问题:**
  1. {openIssue1}
  2. {openIssue2}
* **关键信息/文件:**
  1. {keyInfo1}
  2. {keyInfo2}

---

### 🎯 与你的相关重点
* **【{priority}】{content}**
  * **相关原因:** {reason}
```

## 3. 字段渲染规则

| JSON 字段 | 渲染规则 |
|-----------|----------|
| `groupName` | 缺失时显示"[未提供]" |
| `period` | 缺失时从消息时间推断；仍无法推断则显示"[未提供]" |
| `abstractPoints` | 无序列表，每条一行 |
| `decisions[]` | 有序编号"决议N"；`context` 为空时该行省略 |
| `todos[]` | 表格渲染；`owner`/`dueDate` 未明确时显示"待明确" |
| `topics[]` | "议题 N: title"加粗标题 + 四项子字段列表 |
| `openIssues` | 有序列表 |
| `keyInfo` | 有序列表 |
| `personalHighlights[]` | 有目标用户时渲染；无目标用户时整节省略 |
| `evidenceLinks[]` | **导出时可选追加**"证据引用"附录小节（仅 Agent 团队模式有值） |

---

## 4. 相对参考样式的优化点

在用户提供的参考样式基础上，做以下优化：

1. **新增"分析模式"标注**：头部标注当前摘要来源模式（Agent 团队/单模型基础），导出后人工对比时可直接区分。
2. **personalHighlights 独立小节**：参考样式未包含个性化重点；当存在目标用户时追加"🎯 与你的相关重点"小节，按优先级标注。
3. **证据引用附录（可选）**：Agent 团队模式导出时，可在文末追加证据小节：

```markdown
---

### 📎 证据引用（仅 Agent 团队模式）
| 摘要结论 | 来源消息 |
| :--- | :--- |
| {summaryPoint} | {messageId1}, {messageId2} |
```

4. **空值统一措辞**：负责人/截止日期缺失统一显示"待明确"（与参考样式一致），不使用"未明确"与"待明确"混用。
5. **分隔线统一**：每个一级小节之间使用 `---`，小节内部不使用分隔线。

---

## 5. 导出接口行为

| 导出格式 | 内容 |
|----------|------|
| Markdown | 按本规范渲染的完整简报（可选包含证据附录） |
| JSON | SummaryResult 原始结构化数据 |

导出文件名建议：`{群名}_摘要_{模式}_{版本}.md`，如 `研发群_摘要_单模型_v2.md`。
