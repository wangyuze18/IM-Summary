单样例上，团队模式的准确率提高 4 个百分点，文本相似度提高 0.06；遗漏率和大模型文本评分未提升。这不足以证明数据集级显著增益，需在补齐黄金重要消息后对全部样本做配对比较。

## 4. 已发现并修复的问题

1. 慢速模型服务在 30 秒边界误报超时：连接验证放宽至 120 秒，保存配置后改为后台验证。
2. 生成结果被自动评测阻塞：分析结束后立即刷新摘要，评测后台完成后再刷新指标。
3. 审核 `warning` 统一显示“需修订”：现在依据审核结论区分“需修订”与“有提醒”，且只在分支真正进入 revising 时点亮回退边。
4. 刷新后丢失真实审核状态：前端现在从最近 Run 恢复实际步骤，不再把所有节点伪造为“已完成”。
5. 重要消息明确遗漏被降级为普通警告：审核 Prompt 现在规定待办/决议/风险/审批/阻断/关键进度的遗漏必须为 `error` 并触发定向修订。
6. 评测 JSON 导出因 `Instant` 未注册时间模块而失败：已启用 Java Time ISO-8601 序列化并增加回归测试。
